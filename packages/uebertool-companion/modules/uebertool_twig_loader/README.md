# UEbertool Twig Loader

Attaches a template's library automatically, so themes don't need
`attach_library()` calls. The libraries come from the theme's `*_dist` build
theme generated by vite-plugin-drupal.

## Functionality

- A template `foo.html.twig` of the active theme gets the library `foo` of
  `<theme>_dist` (or of another base theme that defines it).
- A single directory component `<theme>:foo` gets `<theme>_dist/sdc--foo`.

## Traps

- The filesystem loader is skipped on admin routes, so admin templates are
  untouched. On those routes core's loader compiles the template.
- Its Twig cache keys contain the active theme name. The compiled template
  depends on the active theme, and core's loader returns the same key for the
  same file; a shared key would let one compiled version (with or without the
  library) win for all themes and routes.
- Libraries are looked up when a template is compiled. After adding a library,
  rebuild the caches.
